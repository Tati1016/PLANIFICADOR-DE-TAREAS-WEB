# Planificador de Tareas Web

Proyecto individual desarrollado durante el Bootcamp Full Stack Java.

El Planificador de Tareas es una aplicación web orientada a la organización de actividades. Permite visualizar tareas programadas y cuenta con un formulario para registrar la información de nuevas tareas.

El proyecto se desarrollará progresivamente durante los diferentes sprints, incorporando nuevas funcionalidades tanto de frontend como de backend.

## Sprint 1: Planificación e implementación de la interfaz

Durante el Sprint 1 se desarrolló la primera versión funcional de la interfaz del planificador.

Los principales avances fueron:

- Construcción de la estructura principal con HTML5 y Bootstrap 5.
- Implementación del diseño definido previamente en Figma.
- Creación del formulario para registrar tareas.
- Implementación de tarjetas para visualizar las tareas programadas.
- Integración de una lista con cinco tareas de ejemplo.
- Validación de los campos requeridos mediante JavaScript.
- Implementación de mensajes de error utilizando Alert de Bootstrap.
- Adaptación de la interfaz para diferentes tamaños de pantalla.
- Publicación del proyecto mediante GitHub Pages.

## Funcionalidades actuales

- Visualización del resumen de tareas.
- Visualización de tareas programadas.
- Estados de tarea: pendiente, en proceso y completada.
- Formulario para ingresar la información de una tarea.
- Validación de título, descripción, fecha y estado.
- Mensajes de error para campos incompletos.
- Limpieza del formulario y de los mensajes de validación.
- Diseño responsive.

# Planificador de Tareas Web

Proyecto individual desarrollado durante el Bootcamp Full Stack Java.

La aplicación permitirá registrar, organizar y visualizar tareas. El proyecto evolucionará progresivamente durante los diferentes sprints, incorporando nuevas funcionalidades de frontend y backend.

## Sprint 1: Planificación e implementación de la interfaz

Durante este sprint se realizará la planificación inicial del proyecto, el diseño de la interfaz y la organización de las actividades.
